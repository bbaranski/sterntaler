Sterntaler - Kassenfuehrung fuer den Schulfoerderverein
=======================================================
Fassung 1.0.0, fuer Windows und Mac

Diese Fassung laeuft auf Windows und auf Macs ab dem M1-Chip.
Sie setzt voraus, dass Java 21 oder neuer installiert ist
(kostenlos unter https://adoptium.net).

So starten Sie das Programm:

  Windows   start.bat       doppelklicken
  Mac       start.command   doppelklicken

Beim ersten Start meldet macOS einen unbekannten Entwickler. Dann
einmal mit der rechten Maustaste auf start.command klicken und
"Oeffnen" waehlen; danach genuegt der Doppelklick.

Alle Dateien gehoeren in denselben Ordner.

Ohne Java-Installation
----------------------
Im selben Download liegen Pakete, die alles Noetige mitbringen:

  Windows            die Datei mit der Endung .exe
  Mac (M1 und neuer) die Datei mit der Endung .dmg
  Mac mit Intel      die Datei mit "x86_64" im Namen

Diese Jar-Fassung laeuft NICHT auf aelteren Macs mit Intel-Chip -
dafuer bitte das zugehoerige .dmg nehmen.

Das Handbuch finden Sie im laufenden Programm unter "Hilfe".
