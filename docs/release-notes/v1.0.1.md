Diese Fassung ändert nichts am Programm selbst — sie ändert, wie Sie es bekommen.

Sterntaler wird ab jetzt als **eine einzelne startfertige Datei** ausgeliefert, die ein
installiertes [Java 21](https://adoptium.net) voraussetzt. Installationspakete mit eigener
Java-Laufzeit (`.dmg`, `.exe`) gibt es nicht mehr; auch die Dateien der Fassung 1.0.0 stehen
nicht mehr zum Herunterladen bereit.

## Welche Datei Sie brauchen

| Ihr System | Datei |
| --- | --- |
| Mac ab M1 (2020 und neuer) | `Sterntaler-macOS-AppleSilicon.jar` |
| Windows | `Sterntaler-Windows.jar` |

Alles andere bringt die Datei mit. Für Macs mit Intel-Prozessor gibt es keine fertige Datei
zum Herunterladen.

## Beim ersten Start

Die Datei ist nicht signiert, deshalb meldet macOS einen unbekannten Entwickler: mit der
rechten Maustaste darauf klicken, *Öffnen* wählen und einmal bestätigen. Danach genügt der
Doppelklick.

Tut sich auf den Doppelklick gar nichts, ist die Dateiendung `.jar` auf Ihrem Rechner nicht
mit Java verknüpft — dann starten Sie das Programm im Terminal beziehungsweise in der
Eingabeaufforderung mit `java -jar` und dem Namen Ihrer Datei.

Beim allerersten Start fragt das Programm, welche Datenbankdatei es benutzen soll. Für eine
neue Kasse wählen Sie *Neue Datenbank…*. Wie es dann weitergeht, steht im ersten Kapitel des
Handbuchs.

## Was das Programm kann

Buchungen mit Belegen, Kontoumsätze per HBCI/FinTS abrufen (ausschließlich lesend),
Mitgliederverwaltung mit Serienbriefen, Geschäftsjahre mit Abschluss, fünf Berichte als PDF
sowie Excel-Exporte und eine Sicherheitskopie, die alles auf einmal weglegt. Ausführlich steht
das im Handbuch — unter *Hilfe → Handbuch* im Programm und als
[PDF](https://github.com/bbaranski/sterntaler/blob/main/docs/handbuch.pdf).
